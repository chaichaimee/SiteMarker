Introduction

SiteMarker vous permet de placer des « marqueurs » invisibles sur des morceaux de texte spécifiques de n'importe quelle page Web, puis d'y accéder directement plus tard, ou de demander à NVDA de cliquer dessus automatiquement. Au lieu de parcourir une longue page avec les flèches ou la touche Tab à chaque visite, vous appuyez sur un raccourci clavier et atterrissez exactement là où vous devez être — une boîte de discussion, un bouton « Charger plus », un titre spécifique, un bouton « Ignorer l'annonce », ou tout autre élément qui se répète ou est difficile à trouver.


Les marqueurs sont organisés par site Web. Chaque site Web que vous configurez possède son propre ensemble de marqueurs, sa propre règle de correspondance d'URL et son propre comportement de « mode saisie / focalisation ». Tout est enregistré automatiquement, de sorte qu'une fois qu'un site est configuré, les sauts et les clics fonctionnent à chaque fois que vous revenez sur cette page.

NVDA+Windows+F12

Double appui : Ouvrir le Gestionnaire de sites (ou la boîte de dialogue Ajouter un site si le site actuel n'a pas encore été configuré)
Triple appui (ou plus) : Ouvrir le Gestionnaire de marqueurs pour le site actuel
Les appuis sont comptés dans une fenêtre de 0,4 seconde les uns des autres. Appuyer sur le raccourci une fois et attendre brièvement déclenche l'action d'appui simple ; l'appuyer à nouveau rapidement dans cette fenêtre passe à l'action de double appui, et ainsi de suite.

Les touches de saut (J, F, D, Z) et les touches de clic automatique (Alt+J, Alt+C, Alt+X, Alt+Z) ne sont actives que lorsque vous êtes en mode navigation sur un navigateur pris en charge (Chrome, Edge, Firefox, Brave, Opera, Vivaldi ou Thorium). Dans toute autre fenêtre, ou lorsqu'un site n'a aucun marqueur assigné à cette touche, la touche est transmise directement pour qu'elle tape ou se comporte normalement.

Fonctionnalités

Gestionnaire de sites

Chaque site Web pour lequel vous souhaitez des marqueurs doit d'abord être ajouté en tant que « site ». Un site est défini par :


Nom d'affichage — un nom convivial affiché dans la liste du Gestionnaire de sites.
Modèle d'URL — l'adresse ou le texte de domaine qui est vérifié par rapport à la page sur laquelle vous vous trouvez actuellement.
Type de correspondance — la manière dont le modèle est comparé à l'URL réelle de la page :


• Domaine uniquement — le domaine de la page doit correspondre exactement au modèle.
• Inclure les sous-domaines — le domaine doit correspondre au modèle ou se terminer par celui-ci (ainsi un modèle « example.com » correspond également à « mail.example.com »).
• Contenir une sous-chaîne — le modèle doit simplement apparaître n'importe où dans l'URL.
• Correspondance exacte — l'URL entière doit correspondre exactement au modèle.
• Expression régulière — le modèle est traité comme une expression régulière et cherché dans l'URL.


Mode Saisie (Focus) — contrôle la façon dont le comportement normal de NVDA (mode navigation/formulaires) est modifié sur ce site :


• Normal — NVDA se comporte comme d'habitude.
• Ne pas entrer en mode formulaire — lorsqu'un contrôle de ce site reçoit le focus Windows réel, NVDA est empêché de basculer automatiquement en mode formulaire pour cet événement de focus (le mode navigation reste actif).
• Désactiver le focus — la commutation entre le mode navigation et le mode saisie pilotée par les changements de focus réels est entièrement supprimée sur ce site.


Depuis le Gestionnaire de sites, vous pouvez ajouter, modifier ou supprimer un site, et accéder directement au Gestionnaire de marqueurs de ce site. Appuyer sur Suppr sur un site sélectionné (ou F2 pour modifier) fonctionne directement depuis la liste, et un menu contextuel (clic droit) offre les mêmes actions.

Gestionnaire de marqueurs et Propriétés des marqueurs

Chaque site conserve sa propre liste de marqueurs. Un marqueur est une règle qui indique à SiteMarker « lorsque le texte de cette page correspond à ce modèle, c'est un point de repère ». Chaque marqueur possède :


Modèle — le texte (ou l'expression régulière) à rechercher. Lorsque vous ouvrez l'éditeur de marqueurs depuis la page elle-même (via l'appui simple NVDA+Windows+F12), ce champ est pré-rempli avec votre sélection actuelle, le paragraphe actuel sous le curseur ou le nom/valeur du contrôle focalisé, selon ce qui est disponible en premier.
Correspondance de modèle — la manière dont le modèle est comparé à chaque paragraphe de la page :


• Contient du texte — correspond si le modèle apparaît n'importe où dans le paragraphe.
• Paragraphe exact — correspond uniquement si le paragraphe entier est exactement égal au modèle.
• Correspondance Regex — le modèle est traité comme une expression régulière et recherché dans le paragraphe.


Mode — indique si ce marqueur est un marqueur de Saut (déplace votre curseur/position là-bas) ou un marqueur de Clic automatique (active l'élément automatiquement).
Touche — quel raccourci déclenche ce marqueur : J, F, D ou Z pour les marqueurs de saut ; Alt+J, Alt+C, Alt+X ou Alt+Z pour les marqueurs de clic automatique.
Portée de recherche — Document entier recherche sur toute la page (en chargeant plus de contenu plus bas si nécessaire) ; Zone visible restreint la recherche approximativement à la zone actuellement visible de la page (environ 50 paragraphes au-dessus et en dessous de votre curseur).
Nom d'affichage — une étiquette conviviale affichée dans la liste du Gestionnaire de marqueurs.
Décalage (Offset) — de combien de lignes (correspondant à ce que déplacerait un seul appui sur la flèche Haut/Bas) s'éloigner du paragraphe correspondant avant d'atterrir, de -50 à +50. Ceci est utile lorsque le texte que vous pouvez faire correspondre de manière fiable n'est pas exactement la ligne sur laquelle vous souhaitez terminer (par exemple, faire correspondre le nom d'auteur d'un message mais vouloir atterrir deux lignes plus bas, sur le bouton de réponse du message).


La liste du Gestionnaire de marqueurs vous permet d'ajouter, de modifier ou de supprimer un seul marqueur, ou de effacer tous les marqueurs du site en une seule fois. Suppr et F2 pour modifier fonctionnent également directement sur l'élément de liste sélectionné, et un menu contextuel de clic droit duplique ces actions. Si vous ouvrez le raccourci d'appuis multiples sur un paragraphe qui correspond déjà à l'un des marqueurs existants du site, SiteMarker ouvre directement ce marqueur pour modification au lieu de proposer d'en ajouter un nouveau.

Sauter vers les marqueurs (J / F / D / Z)

Appuyer sur une touche de saut analyse paragraphe par paragraphe, en avant ou en arrière à partir de votre position actuelle, à la recherche de tout marqueur assigné à cette touche. Dès qu'une correspondance est trouvée :


1. Si le marqueur a un décalage, SiteMarker se déplace de ce nombre de lignes par rapport au paragraphe correspondant (ou, si un modèle de décalage est défini, continue à rechercher dans les lignes voisines une ligne correspondant à ce modèle au lieu d'un nombre de lignes fixe) avant d'atterrir.
2. Si le décalage vous faisait atterrir sur un paragraphe vide, SiteMarker continue d'avancer jusqu'à ce qu'il atteigne du texte non vide.
3. Votre curseur y est déplacé et NVDA énonce le texte de destination.


Si la partie visible de la page s'épuise avant qu'une correspondance ne soit trouvée (par exemple, une page de style « flux » sans fin), SiteMarker envoie automatiquement Page Suivante pour charger plus de contenu et continue la recherche, jusqu'à 100 tentatives de chargement. Si rien n'est trouvé après tout cela, ou après 5 tentatives consécutives qui n'ont ajouté aucun nouveau contenu, vous entendreez « Pas de marqueur suivant » ou « Pas de marqueur précédent ».


SiteMarker évite d'annoncer à nouveau exactement le même endroit deux fois de suite (certaines pages répètent un texte identique à plusieurs endroits dans l'arbre d'accessibilité sous-jacent) et ignore les correspondances qui se trouvent à l'intérieur d'un champ modifiable ou d'une zone combinée, en réessayant au-delà.

Clic automatique (Alt+J / Alt+C / Alt+X / Alt+Z)

Appuyer sur une touche de clic automatique analyse la page depuis le tout début à la recherche d'un marqueur assigné à cette touche, applique son décalage de la même manière que les marqueurs de saut, puis clique sur l'élément correspondant à l'aide d'un système de secours en trois étapes pour que même les boutons récalcitrants (comme le bouton « Ignorer l'annonce » d'un site vidéo) soient activés de manière fiable :


1. Essayer la propre commande d'accessibilité « exécuter l'action » de l'élément.
2. Si elle n'est pas disponible, essayer de l'invoquer via son modèle UI Automation Invoke.
3. Si les deux échouent, déplacer le curseur de la souris sur l'élément et simuler un clic gauche physique.


Après un clic réussi, NVDA énonce le texte cliqué et annonce « Cliqué ». Sur YouTube spécifiquement, si l'URL de la page et le texte sous le curseur n'ont pas changé peu de temps après le clic (signe que le clic n'a pas été enregistré, ce qui peut se produire avec un bouton d'ignorage pas encore totalement interactif), SiteMarker réessaye automatiquement le clic jusqu'à 2 fois de plus. Sur d'autres sites, ce re-clic automatique est ignoré, car un contrôle de type bascule peut réussir au premier clic tout en paraissant inchangé, et un nouveau clic le désactiverait simplement à nouveau.


Si aucune cible cliquable correspondante n'est trouvée à la fin de la page, SiteMarker réessaye automatiquement toute la recherche jusqu'à 5 fois avec un court délai croissant entre les tentatives (pour attraper des éléments, comme le bouton d'ignorage d'une publicité, qui n'apparaissent qu'une seconde ou deux après le chargement de la page), avant d'annoncer finalement « Aucune cible de clic automatique trouvée ».

Récupération automatique du vol de focus

Sur certaines pages, le défilement automatique « charger plus » effectué par SiteMarker lors d'une analyse peut accidentellement placer le focus clavier réel sur un champ modifiable ou une zone de recherche sans rapport au lieu de faire simplement défiler la page. Lorsque cela se produit lors d'une analyse active, SiteMarker restaure automatiquement le focus sur le document afin que votre recherche ne soit pas interrompue. Si la même page continue de voler le focus sur le même champ peu importe le nombre de fois que cela est corrigé, SiteMarker arrête d'essayer de faire défiler davantage pour cette analyse et termine simplement la recherche avec le contenu déjà chargé.

Détection des modifications de page en arrière-plan

SiteMarker revérifie automatiquement les marqueurs actifs chaque fois que vous changez de focus, chaque fois que le contenu de la page se met à jour, et sur une minuterie périodique (toutes les 2 secondes environ) lorsque vous êtes sur une page de navigateur. Cela maintient vos marqueurs à jour sur les applications à page unique et les sites à mise à jour dynamique sans que vous ayez à faire quoi que ce soit manuellement.

Stockage des données par site

Tous vos sites et leurs marqueurs sont enregistrés automatiquement dans votre dossier de configuration utilisateur NVDA (sous un dossier SiteMarker) sous forme d'un fichier par site, de sorte que votre configuration est préservée entre les sessions NVDA et ne nécessite aucune connexion Internet pour fonctionner.
