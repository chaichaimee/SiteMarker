SiteMarker

Marquez votre chemin, sautez avec aisance

auteur: chai chaimee

url: https://github.com/chaichaimee/SiteMarker


Introduction

SiteMarker est un module complémentaire NVDA qui vous permet d'enregistrer et d'accéder rapidement aux sections fréquemment utilisées de n'importe quel site Web. Avec seulement quelques frappes, vous pouvez marquer des paragraphes, des boutons ou des contrôles importants et y revenir instantanément – fini le défilement sans fin ou la recherche de cet endroit précis.


Fonctionnalités

  • Placez des marqueurs permanents sur n'importe quel élément d'une page Web.
  • Sautez en avant ou en arrière vers les marqueurs à l'aide de touches dédiées (J, F, D, Z).
  • Les marqueurs à clic automatique activent automatiquement les boutons, liens ou contrôles de formulaire.
  • Gérez les sites et les marqueurs via un Gestionnaire de Sites et un Gestionnaire de Marqueurs simples.
  • Partagez vos configurations de marqueurs entre appareils via des fichiers JSON portables.
  • Fonctionne avec Chrome, Edge, Firefox, Brave et les navigateurs basés sur WebKit.
  • Prend en charge les applications monopage (SPA) avec détection automatique du contenu.
  • Correspondance flexible avec des motifs textuels, exacts ou d'expressions régulières.

Avantages

  • Gagnez du temps – éliminez les défilements répétitifs et la navigation par touches fléchées.
  • Réduisez la fatigue des frappes – des sauts rapides en une seule touche gardent vos mains confortables.
  • Augmentez la productivité – créez des raccourcis personnalisés pour vos tâches les plus fréquentes.
  • Restez orienté – un retour vocal à chaque saut vous informe de votre position.

Pourquoi l'utiliser

Chaque jour, vous visitez les mêmes sites Web – pour lire, remplir des formulaires, consulter des tableaux de bord. Se déplacer entre les sections clés peut être fastidieux et fatigant. SiteMarker résout ce problème en vous permettant de placer des marqueurs exactement aux endroits dont vous avez besoin. Plus de recherche ; marquez, sautez et concentrez-vous sur l'essentiel.


Commencez dès aujourd'hui

SiteMarker transforme n'importe quel site Web en un terrain de jeu de navigation personnalisé. Téléchargez-le maintenant et découvrez la liberté d'un accès instantané aux parties du Web qui comptent le plus pour vous.



Premiers pas – Étape par étape


1. Ajoutez votre premier site

Lorsque vous ouvrez un site Web où vous souhaitez utiliser des marqueurs, appuyez deux fois sur Windows+F12. La boîte de dialogue Ajouter un site apparaît.

  • Nom affiché : Donnez à votre site un nom convivial (ex. "Boîte de réception Gmail" ou "Actualités quotidiennes").

  • Modèle d'URL : Saisissez l'adresse Web (ou une partie) qui identifie ce site.

  • Type de correspondance : Choisissez comment SiteMarker doit faire correspondre l'URL actuelle à votre modèle.

    Domaine uniquement – Correspond uniquement au domaine principal (ex. modèle google.com fonctionne pour www.google.com et mail.google.com, mais pas pour google.co.uk).

    Inclure les sous-domaines – L'URL doit se terminer par votre modèle. Par exemple, le modèle example.com correspond à sub.example.com et news.example.com, mais pas à example.org.

    Contenir une sous-chaîne – Correspond si votre modèle apparaît n'importe où dans l'URL complète (y compris le chemin et la requête). Exemple : modèle /search correspond à https://www.google.com/search?q=test.

    Correspondance exacte – L'URL entière doit être exactement égale à votre modèle (insensible à la casse). Utilisez ceci lorsque vous voulez des marqueurs uniquement pour une page spécifique, comme https://example.com/dashboard.

    Expression régulière – Pour les utilisateurs avancés. Écrivez un modèle regex (ex. https://.*\.example\.com/.*) pour correspondre à n'importe quelle page sous n'importe quel sous-domaine de example.com.

Cliquez sur Enregistrer le site. Votre site est maintenant enregistré et vous pouvez commencer à placer des marqueurs.


2. Placez votre premier marqueur

Naviguez jusqu'au paragraphe, à la ligne ou au bouton exact que vous souhaitez mémoriser. Ensuite, appuyez une fois sur Windows+F12. La boîte de dialogue Ajouter un marqueur s'ouvre.

  • Modèle – SiteMarker remplit automatiquement ce champ avec le texte actuellement sous le focus. Vous pouvez le modifier si nécessaire. Ce texte est ce que SiteMarker recherche.

  • Correspondance du modèle – Choisissez comment le modèle doit être comparé :

    Contient le texte – Trouve le modèle n'importe où dans le paragraphe (correspondance partielle).

    Paragraphe exact – Le paragraphe doit être exactement égal au modèle (correspondance de texte entier).

    Correspondance regex – Utilisez une expression régulière pour une correspondance avancée.

  • Mode – Décidez ce que fait ce marqueur :

    Sauter – Lorsque vous appuyez sur la touche de saut attribuée, le curseur se déplace vers ce marqueur. Vous pouvez attribuer l'une des quatre touches de saut : J, F, D ou Z. Appuyez sur la touche seule pour sauter en avant vers le prochain marqueur avec cette touche. Appuyez sur Maj+touche pour sauter en arrière.

    Clic automatique – Au lieu de simplement déplacer le focus, SiteMarker effectuera automatiquement un clic sur l'élément lorsque vous appuyez sur la touche de clic attribuée. Les touches de clic disponibles sont Alt+J, Alt+C, Alt+X et Alt+Z.

  • Nom affiché – Donnez à votre marqueur un nom significatif (ex. "Bouton Envoyer" ou "Section Résumé").

  • Décalage – Cela déplace la position finale du curseur par rapport au marqueur trouvé. Saisissez un nombre entier (positif ou négatif) pour décaler la position d'atterrissage.

    Nombre positif (ex. 2) déplace le curseur en avant de ce nombre de paragraphes après le marqueur.

    Nombre négatif (ex. -1) déplace le curseur en arrière de ce nombre de paragraphes avant le marqueur.

    0 (par défaut) atterrit exactement sur le marqueur lui-même.

Cliquez sur OK – votre marqueur est enregistré et prêt à être utilisé.



Sautez et cliquez comme un pro

Une fois que vous avez configuré des marqueurs, vous pouvez naviguer sur votre site sans effort :

  • Appuyez sur J, F, D ou Z (seuls) pour sauter en avant vers le prochain marqueur attribué à cette touche.
  • Appuyez sur Maj+J, Maj+F, Maj+D ou Maj+Z pour sauter en arrière vers le marqueur précédent.
  • Pour les marqueurs à clic automatique, appuyez sur Alt+J, Alt+C, Alt+X ou Alt+Z – le curseur trouvera le prochain marqueur correspondant et cliquera automatiquement sur l'élément cible.

Chaque saut prononce le paragraphe cible à haute voix et déplace le curseur de révision d'écran vers cette position, afin que vous sachiez toujours où vous êtes.


Gérer tout

Vous pouvez toujours appuyer deux fois sur Windows+F12 pour ouvrir le Gestionnaire de Sites. À partir de là, vous pouvez :

  • Modifier le nom affiché, le modèle d'URL ou le type de correspondance d'un site.
  • Ajouter, modifier ou supprimer des marqueurs pour n'importe quel site.
  • Supprimer tous les marqueurs d'un coup.
  • Naviguer d'avant en arrière entre la liste des sites et la liste des marqueurs.

Le Gestionnaire de Marqueurs (accessible depuis le Gestionnaire de Sites) vous donne un aperçu complet de tous les marqueurs pour le site actuel, avec des options rapides pour modifier ou supprimer chacun d'eux.


Partagez vos marqueurs

Toutes vos configurations de sites et de marqueurs sont stockées dans un simple fichier JSON pour chaque site. Ces fichiers se trouvent dans : 

%APPDATA%\nvda\ChaiChaimee\SiteMarker\site\

Vous pouvez copier ces fichiers .json sur un autre ordinateur ou les partager avec des collègues. Placez-les simplement dans le même dossier sur l'autre machine, et SiteMarker reconnaîtra instantanément les sites et les marqueurs – aucune configuration supplémentaire n'est nécessaire. Cela facilite le partage de configurations de navigation intelligentes entre équipes ou appareils.
