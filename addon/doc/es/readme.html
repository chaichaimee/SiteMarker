Introducción

SiteMarker es un complemento de NVDA que le permite guardar y acceder rápidamente a secciones utilizadas con frecuencia de cualquier sitio web. Con solo unas pocas pulsaciones de teclas, puede marcar párrafos, botones o controles importantes y volver a ellos al instante – no más desplazamientos interminables ni búsquedas de ese lugar específico.


Características

  • Coloque marcadores permanentes en cualquier elemento dentro de una página web.
  • Salte hacia adelante o hacia atrás a marcadores usando teclas dedicadas (J, F, D, Z).
  • Los marcadores de clic automático activan botones, enlaces o controles de formulario automáticamente.
  • Administre sitios y marcadores a través de un Administrador de Sitios y un Administrador de Marcadores simples.
  • Comparta sus configuraciones de marcadores entre dispositivos a través de archivos JSON portátiles.
  • Funciona con Chrome, Edge, Firefox, Brave y navegadores basados en WebKit.
  • Admite aplicaciones de una sola página (SPA) con detección automática de contenido.
  • Coincidencia flexible con patrones de texto, exactos o de expresión regular.

Beneficios

  • Ahorre tiempo – elimine el desplazamiento repetitivo y la navegación con teclas de flecha.
  • Reduzca la fatiga de las teclas – los saltos rápidos con una sola tecla mantienen sus manos cómodas.
  • Aumente la productividad – cree accesos directos personalizados para sus tareas más frecuentes.
  • Manténgase orientado – la retroalimentación hablada en cada salto le mantiene al tanto de su ubicación.

Por qué usarlo

Cada día, visita los mismos sitios web – leyendo, completando formularios, revisando paneles. Moverse entre secciones clave puede ser tedioso y agotador. SiteMarker resuelve esto permitiéndole colocar marcadores exactamente en los lugares que necesita. No más búsquedas; simplemente marque, salte y concéntrese en lo que importa.


Comience hoy

SiteMarker convierte cualquier sitio web en un patio de juegos de navegación personalizado. Descárguelo ahora y experimente la libertad de acceso instantáneo a las partes de la web que más le importan.



Primeros pasos – Paso a paso


1. Agregue su primer sitio

Cuando abra un sitio web donde desee usar marcadores, pulse dos veces Windows+F12. Aparecerá el diálogo Agregar Sitio.

  • Nombre para mostrar: Asigne un nombre amigable a su sitio (ej. "Bandeja de entrada de Gmail" o "Noticias diarias").

  • Patrón de URL: Ingrese la dirección web (o parte de ella) que identifica este sitio.

  • Tipo de coincidencia: Elija cómo SiteMarker debe comparar la URL actual con su patrón.

    Solo dominio – Coincide solo con el dominio principal (ej. patrón google.com funciona para www.google.com y mail.google.com, pero no para google.co.uk).

    Incluir subdominios – La URL debe terminar con su patrón. Por ejemplo, el patrón example.com coincide con sub.example.com y news.example.com, pero no con example.org.

    Contener subcadena – Coincide si su patrón aparece en cualquier parte de la URL completa (incluyendo ruta y consulta). Ejemplo: patrón /search coincide con https://www.google.com/search?q=test.

    Coincidencia exacta – La URL completa debe ser exactamente igual a su patrón (sin distinción de mayúsculas/minúsculas). Use esto cuando desee marcadores solo para una página específica, como https://example.com/dashboard.

    Expresión regular – Para usuarios avanzados. Escriba un patrón regex (ej. https://.*\.example\.com/.*) para coincidir con cualquier página bajo cualquier subdominio de example.com.

Haga clic en Guardar Sitio. Su sitio ahora está registrado y puede comenzar a colocar marcadores.


2. Coloque su primer marcador

Navegue hasta el párrafo, línea o botón exacto que desea recordar. Luego, pulse una vez Windows+F12. Se abrirá el diálogo Agregar Marcador.

  • Patrón – SiteMarker completa automáticamente este campo con el texto que está actualmente en foco. Puede editarlo si es necesario. Este texto es lo que SiteMarker busca.

  • Coincidencia de patrón – Elija cómo se debe comparar el patrón:

    Contiene texto – Encuentra el patrón en cualquier lugar dentro del párrafo (coincidencia parcial).

    Párrafo exacto – El párrafo debe ser exactamente igual al patrón (coincidencia de texto completo).

    Coincidencia regex – Use una expresión regular para coincidencias avanzadas.

  • Modo – Decida lo que hace este marcador:

    Saltar – Cuando presiona la tecla de salto asignada, el cursor se mueve a este marcador. Puede asignar una de cuatro teclas de salto: J, F, D o Z. Presione la tecla sola para saltar hacia adelante al siguiente marcador con esa tecla. Presione Mayús+tecla para saltar hacia atrás.

    Clic automático – En lugar de solo mover el foco, SiteMarker hará automáticamente clic en el elemento cuando presione la tecla de clic asignada. Las teclas de clic disponibles son Alt+J, Alt+C, Alt+X y Alt+Z.

  • Nombre para mostrar – Asigne un nombre significativo a su marcador (ej. "Botón Enviar" o "Sección de Resumen").

  • Desplazamiento – Esto mueve la posición final del cursor en relación con el marcador encontrado. Ingrese un número entero (positivo o negativo) para desplazar la posición de llegada.

    Número positivo (ej. 2) mueve el cursor hacia adelante esa cantidad de párrafos después del marcador.

    Número negativo (ej. -1) mueve el cursor hacia atrás esa cantidad de párrafos antes del marcador.

    0 (predeterminado) aterriza exactamente en el marcador mismo.

Haga clic en Aceptar – su marcador se guarda y está listo para usar.



Salte y haga clic como un profesional

Una vez que tenga marcadores configurados, puede navegar por su sitio sin esfuerzo:

  • Presione J, F, D o Z (solos) para saltar hacia adelante al siguiente marcador asignado a esa tecla.
  • Presione Mayús+J, Mayús+F, Mayús+D o Mayús+Z para saltar hacia atrás al marcador anterior.
  • Para marcadores de clic automático, presione Alt+J, Alt+C, Alt+X o Alt+Z – el cursor encontrará el siguiente marcador coincidente y hará clic en el elemento objetivo automáticamente.

Cada salto lee el párrafo objetivo en voz alta y mueve el cursor de revisión de pantalla a esa posición, para que siempre sepa dónde está.


Gestionando todo

Siempre puede pulsar dos veces Windows+F12 para abrir el Administrador de Sitios. Desde allí puede:

  • Editar el nombre para mostrar, el patrón de URL o el tipo de coincidencia de un sitio.
  • Agregar, editar o eliminar marcadores para cualquier sitio.
  • Eliminar todos los marcadores de una vez.
  • Navegar de un lado a otro entre la lista de sitios y la lista de marcadores.

El Administrador de Marcadores (accesible desde el Administrador de Sitios) le ofrece una visión completa de todos los marcadores para el sitio actual, con opciones rápidas para editar o eliminar cada uno.


Comparta sus marcadores

Todas sus configuraciones de sitios y marcadores se almacenan en un simple archivo JSON para cada sitio. Estos archivos se encuentran en: 

%APPDATA%\nvda\ChaiChaimee\SiteMarker\site\

Puede copiar estos archivos .json a otra computadora o compartirlos con colegas. Simplemente colóquelos en la misma carpeta en la otra máquina, y SiteMarker reconocerá instantáneamente los sitios y marcadores – sin necesidad de configuración adicional. Esto facilita compartir configuraciones de navegación inteligentes entre equipos o dispositivos.
