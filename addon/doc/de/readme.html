SiteMarker


Setzen Sie Lesezeichen für eine beliebige Stelle auf einer Webseite und springen Sie bei jedem Besuch direkt dorthin zurück – kein langes Zeile-für-Zeile-Suchen mehr auf langen Seiten.


Autor: chai chaimee

URL: https://github.com/chaichaimee/SiteMarker


Einführung

Besuchen Sie immer wieder dieselben Websites und müssen jedes Mal aufs Neue scrollen oder nach derselben Schaltfläche, Überschrift oder demselben Eingabefeld suchen? Mit SiteMarker können Sie jeden beliebigen Punkt auf einer Seite „markieren“ – anhand des Textes in dessen Nähe – und dann mit einem einzigen Tastendruck direkt dorthin zurückspringen oder den Punkt sogar automatisch von NVDA anklicken lassen.


Stellen Sie sich das wie persönliche Lesezeichen für das Web vor, aber intelligenter: Statt sich die Position einer Bildlaufleiste zu merken, merkt sich SiteMarker einen Textabschnitt (wie „Werbung überspringen“, „Antworten“ oder den Namen eines Freundes in einer Chat-Liste) und findet ihn für Sie wieder, selbst wenn sich das Layout der Seite seit Ihrem letzten Besuch verändert hat.


SiteMarker funktioniert pro Website: Sie richten Ihre Marker einmalig für eine Website ein (z. B. YouTube, Facebook, Webmail-Posteingang), und von da an funktionieren Ihre Tastenkürzel automatisch, wann immer Sie diese Website besuchen. Es läuft im Hintergrund, während Sie Chrome, Edge, Firefox, Brave, Opera, Vivaldi oder Thorium nutzen, und hält sich überall sonst im Hintergrund.

Tastenkombinationen

NVDA+Windows+F12
Einmal drücken : Marker für den aktuellen Absatz hinzufügen oder bearbeiten
Zweimal drücken : Website-Manager öffnen (oder Website hinzufügen, falls diese Seite noch nicht eingerichtet ist)
Dreimal drücken : Marker-Manager für die aktuelle Website öffnen
Diese eine Tastenkombination führt drei verschiedene Aktionen aus, je nachdem, wie oft Sie sie schnell hintereinander drücken (innerhalb von etwa vier Zehntelsekunden):

Einmal drücken — Befindet sich Ihr Cursor auf Text, der bereits mit einem Ihrer Marker übereinstimmt, wird direkt der Eigenschaften-Dialog dieses Markers geöffnet, damit Sie ihn bearbeiten können. Andernfalls wird der Marker-Manager geöffnet und sofort mit dem Hinzufügen eines völlig neuen Markers auf der Grundlage des Textes begonnen, auf dem sich Ihr Cursor oder Fokus befindet.

Zweimal drücken — Öffnet den Website-Manager für die Website, auf der Sie sich gerade befinden, damit Sie Websites überprüfen, hinzufügen, bearbeiten oder löschen und in deren Marker-Listen wechseln können. Wenn die aktuelle Website noch nicht konfiguriert wurde, wird stattdessen der Dialog „Website hinzufügen“ geöffnet, vorausgefüllt mit der Domain der aktuellen Seite.

Dreimal drücken (oder mehr) — Springt direkt zum Marker-Manager für die aktuelle Website und überspringt den Website-Manager. Wenn für die aktuelle Seite noch keine Website konfiguriert ist, werden Sie aufgefordert, zuerst eine Website hinzuzufügen.
J
Zum nächsten diesem Kürzel zugewiesenen Marker springen
Shift+J
Zum vorherigen diesem Kürzel zugewiesenen Marker springen
Alt+J
Das Element, das mit dem diesem Kürzel zugewiesenen Marker übereinstimmt, automatisch anklicken
J, Shift+J und Alt+J sind die einzigen Tasten für Sprung/Automatisches Anklicken, die von SiteMarker standardmäßig reserviert sind. Dies geschieht bewusst: Jede andere Buchstabentaste (wie F, D oder Z) bleibt für die eigene Navigation im Browse-Modus von NVDA vollständig frei, es sei denn, Sie entscheiden sich ausdrücklich dafür, sie zu verwenden. Wenn Sie weitere Tastenkürzel wünschen, weisen Sie einem Marker stattdessen ein Benutzerdefiniertes Tastenkürzel zu (siehe Funktionen unten) — diese Taste wird dann nur auf Websites aktiv, auf denen Sie sie tatsächlich verwendet haben, und nur, während Sie sich auf diesen Websites befinden.

Funktionen

1. Text auf einer Seite markieren

Ein „Marker“ weist SiteMarker an, nach einem bestimmten Textabschnitt auf einer bestimmten Website zu suchen. Wenn Sie die zugewiesene Taste drücken, durchsucht SiteMarker die Seite nach diesem Text und führt Sie dorthin (oder klickt ihn an, wenn er auf Automatischer Klick eingestellt ist).

Jeder Marker verfügt über diese Einstellungen im Dialogfeld Marker-Eigenschaften (geöffnet über die Schaltflächen Hinzufügen/Bearbeiten im Marker-Manager oder automatisch über die Tastenkombination NVDA+Windows+F12 bei einmaligem Drücken):

  • Muster — der Text, nach dem SiteMarker sucht. Wird automatisch aus Ihrer aktuellen Auswahl oder Cursorposition vorausgefüllt, wenn Sie diesen Dialog öffnen.
  • Musterübereinstimmung — wie das Muster mit jedem Absatz auf der Seite verglichen wird:
    • Enthält Text — stimmt überein, wenn der Absatz Ihr Muster an beliebiger Stelle enthält.
    • Exakter Absatz — stimmt nur überein, wenn der gesamte Absatz exakt Ihrem Muster entspricht.
    • Regex-Übereinstimmung — behandelt Ihr Muster als regulären Ausdruck für erweiterte Übereinstimmungen.
  • Modus — Sprung (Cursor dorthin bewegen und vorlesen) oder Automatischer Klick (automatisch aktivieren/anklicken).
  • Taste — standardmäßig J für einen Sprung-Marker oder Alt+J für einen Auto-Klick-Marker oder Ihr eigenes Benutzerdefiniertes Tastenkürzel (siehe unten).
  • Auto-Sprung / Auto-Klick beim Laden der Seite — wenn aktiviert, wird dieser Marker automatisch ausgeführt, sobald die Seite vollständig geladen ist, ganz ohne Tastendruck.
  • Suchbereich — Ganzes Dokument durchsucht die gesamte Seite (lädt auf langen Seiten oder Seiten mit unendlichem Scrollen automatisch mehr Inhalt nach), während Nur Bildschirmausschnitt die Suche auf die ungefähre Umgebung Ihrer aktuellen Position beschränkt, was auf sehr langen Seiten schneller ist.
  • Anzeigename — die Bezeichnung, die für diesen Marker in der Liste des Marker-Managers angezeigt wird. Standardmäßig das Muster, wenn es leer gelassen wird.
  • Versatz — wie viele Zeilen nach oben oder unten navigiert werden soll, nachdem die Übereinstimmung gefunden wurde, bevor die Zielposition erreicht wird – genau wie das mehrmalige Drücken der Pfeiltaste nach oben oder unten. Eine negative Zahl bewegt sich nach oben, eine positive Zahl nach unten. Nützlich, wenn Sie eigentlich die Zeile direkt über oder unter Ihrem gematchten Text ansteuern möchten, nicht den Treffer selbst.

2. Benutzerdefinierte Tastenkürzel pro Marker

Anstatt die gemeinsamen Tasten J oder Alt+J zu verwenden, kann jedem Marker über die Schaltfläche Benutzerdefiniertes Tastenkürzel... in den Marker-Eigenschaften ein eigenes Tastenkürzel zugewiesen werden. Drücken Sie die Schaltfläche und drücken Sie dann einfach die gewünschte Tastenkombination — SiteMarker erfasst sie und zeigt sie Ihnen an.

Bei einem Marker im Sprung-Modus wird durch das Zuweisen einer benutzerdefinierten Taste automatisch auch Umschalt+diese Taste zum Rückwärtsspringen zugewiesen, analog zur Paarung von Umschalt+J mit J. Die Auswahl von Standardtaste verwenden setzt den Marker wieder auf die gemeinsame Taste J oder Alt+J zurück. Benutzerdefinierte Tastenkürzel werden nur aktiv, während Sie sich auf einer Website befinden, die diese tatsächlich verwendet, sodass sie niemals Ihre anderen Erweiterungen oder NVDA an anderer Stelle beeinträchtigen.

3. Website-Manager

Der über NVDA+Windows+F12 (zweimal drücken) geöffnete Website-Manager listet jede Website auf, für die Sie Marker konfiguriert haben. Von hier aus können Sie:

  • Neue Website hinzufügen — eine neue Website einrichten, wobei die URL von Ihrem aktuellen Standort vorausgefüllt wird.
  • Website bearbeiten — die Einstellungen einer Website ändern (siehe unten).
  • Website löschen — eine Website und alle ihre Marker entfernen (mit Bestätigungsaufforderung).
  • Marker verwalten — in den Marker-Manager dieser Website wechseln.

Das Drücken von Entf oder F2, während eine Website in der Liste ausgewählt ist, löscht oder bearbeitet diese ebenfalls, und ein Kontextmenü per Rechtsklick bietet dieselben Aktionen.

Jede Website verfügt über diese Einstellungen im Dialogfeld Website hinzufügen/bearbeiten:

  • Anzeigename — der für diese Website in der Liste angezeigte Name.
  • URL-Muster — die Adresse oder Domain, für die diese Konfiguration gilt.
  • Übereinstimmungstyp — wie das URL-Muster mit der von Ihnen durchsuchten Seite verglichen wird:
    • Nur Domain — stimmt nur mit dieser exakten Domain überein.
    • Subdomains einschließen — stimmt auch mit Subdomains dieser Domain überein.
    • Teilzeichenfolge enthalten — stimmt überein, wenn die Adresse der Seite diesen Text an beliebiger Stelle enthält.
    • Exakte Übereinstimmung — stimmt nur mit dieser exakten, vollständigen Adresse überein.
    • Regulärer Ausdruck — stimmt mithilfe eines regulären Ausdrucks für erweiterte Muster überein.
  • Fokus-Modus — steuert, wie sich der eigene Fokus-/Formular-Modus von NVDA auf dieser Website verhält:
    • Normal — NVDA verhält sich wie gewohnt.
    • Formular-Modus nicht aktivieren — verhindert, dass NVDA automatisch in den Formular-Modus wechselt, wenn sich der Fokus bewegt. Nützlich auf Websites, auf denen dieser Wechsel störender als hilfreich ist.
    • Fokus deaktivieren — hält den Browse-Modus aktiv, unabhängig davon, was auf der Seite den Fokus erhält.
  • Leere Zeilen beim Navigieren mit Pfeil-auf/ab und Strg+Pfeil-auf/ab überspringen — wenn aktiviert, überspringt das Drücken dieser Pfeiltasten auf dieser Website automatisch leere Zeilen/Absätze, anstatt darauf anzuhalten, sodass Sie direkt auf der nächsten Zeile oder dem nächsten Absatz mit Inhalt landen.

4. Marker-Manager

Listet jeden Marker auf, der für eine bestimmte Website eingerichtet wurde. Von hier aus können Sie einen einzelnen Marker hinzufügen, bearbeiten oder löschen oder Alle löschen verwenden, um alle Marker für diese Website auf einmal zu entfernen (jeweils mit Bestätigungsaufforderung). Das Drücken von Entf oder F2 auf einem ausgewählten Marker oder ein Rechtsklick darauf bietet Ihnen dieselben Optionen. Eine Schaltfläche Zurück zum Website-Manager führt Sie zurück zur Websiteliste.

5. Automatisches Nachladen von weiteren Inhalten

Auf Seiten, die beim Scrollen weitere Inhalte nachladen (Social-Media-Feeds, Chat-Verläufe und ähnliche Seiten mit unendlichem Scrollen), scrollt ein Sprung-Marker, der auf die Suche im Ganzen Dokument eingestellt ist, die Seite automatisch weiter nach unten, wenn er das Ende des aktuell Geladenen erreicht, ohne eine Übereinstimmung zu finden. Er sucht dann weiter – bis zu einer großzügigen Anzahl von Versuchen –, bevor er Ihnen mitteilt, dass keine Übereinstimmung gefunden wurde.

6. Zuverlässiges Anklicken, auch bei hartnäckigen Schaltflächen

Wenn der Modus eines Markers auf Automatischer Klick eingestellt ist, versucht SiteMarker verschiedene Wege, um das gefundene Element zu aktivieren (standardmäßige NVDA-Aktion, dann eine modernere Barrierefreiheits-Schnittstelle und schließlich als letzte Option ein echter simulierter Mausklick). So können auch Schaltflächen erfolgreich angeklickt werden, die nicht immer auf die einfachste Methode reagieren – wie die Schaltfläche „Werbung überspringen“ auf Videoseiten. Speziell auf YouTube versucht SiteMarker den Klick automatisch noch ein paar Mal, falls er noch nicht gewirkt hat.

7. Fokus-Schutz während des Scans

Während SiteMarker eine Seite scrollt, um mehr Inhalt für einen Scan nachzuladen, ist es (auf einigen Websites) möglich, dass das Scrollen Ihren echten Tastaturfokus versehentlich auf einem Suchfeld oder einem anderen bearbeitbaren Feld platziert, anstatt auf der Seite zu bleiben. SiteMarker erkennt dies automatisch und stellt Ihren Fokus wieder auf das Dokument her, damit ein laufender Sprung oder Auto-Klick nicht unterbrochen wird.
