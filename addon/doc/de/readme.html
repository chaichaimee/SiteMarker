SiteMarker

Markieren Sie Ihren Weg, springen Sie mit Leichtigkeit

Autor: chai chaimee

URL: https://github.com/chaichaimee/SiteMarker


Einleitung

SiteMarker ist ein NVDA-Add-on, mit dem Sie häufig verwendete Abschnitte beliebiger Websites schnell speichern und aufrufen können. Mit nur wenigen Tastendrücken können Sie wichtige Absätze, Schaltflächen oder Steuerelemente markieren und sofort zu ihnen zurückspringen – kein endloses Scrollen oder Suchen nach einer bestimmten Stelle mehr.


Funktionen

  • Platzieren Sie permanente Markierungen auf jedem Element innerhalb einer Webseite.
  • Springen Sie mit dedizierten Tasten vorwärts oder rückwärts zu Markierungen (J, F, D, Z).
  • Auto‑Klick-Markierungen aktivieren automatisch Schaltflächen, Links oder Formularelemente.
  • Verwalten Sie Websites und Markierungen über einen einfachen Site-Manager und Marker-Manager.
  • Teilen Sie Ihre Markierungskonfigurationen über tragbare JSON-Dateien auf verschiedenen Geräten.
  • Funktioniert mit Chrome, Edge, Firefox, Brave und WebKit-basierten Browsern.
  • Unterstützt Single‑Page‑Anwendungen (SPA) mit automatischer Inhaltserkennung.
  • Flexible Übereinstimmung mit Text-, exakten oder regulären Ausdrucksmustern.

Vorteile

  • Zeitsparen – vermeiden Sie wiederholtes Scrollen und Navigieren mit den Pfeiltasten.
  • Reduzieren Sie die Tastaturbelastung – schnelle Sprünge mit einer Taste schonen Ihre Hände.
  • Steigern Sie die Produktivität – erstellen Sie personalisierte Verknüpfungen für Ihre häufigsten Aufgaben.
  • Behalten Sie die Orientierung – Sprachausgabe bei jedem Sprung gibt Rückmeldung über Ihre Position.

Warum es verwenden

Jeden Tag besuchen Sie dieselben Websites – lesen, füllen Formulare aus, prüfen Dashboards. Die Navigation zwischen wichtigen Abschnitten kann mühsam und ermüdend sein. SiteMarker löst dieses Problem, indem Sie Markierungen genau an den Stellen platzieren können, die Sie benötigen. Kein Suchen mehr; einfach markieren, springen und sich auf das Wesentliche konzentrieren.


Jetzt loslegen

SiteMarker verwandelt jede Website in einen personalisierten Navigationsspielplatz. Laden Sie es jetzt herunter und erleben Sie die Freiheit des sofortigen Zugriffs auf die Teile des Internets, die Ihnen am wichtigsten sind.



Erste Schritte – Schritt für Schritt


1. Fügen Sie Ihre erste Website hinzu

Wenn Sie eine Website öffnen, auf der Sie Markierungen verwenden möchten, tippen Sie doppelt auf Windows+F12. Der Dialog Website hinzufügen wird angezeigt.

  • Anzeigename: Geben Sie Ihrer Website einen aussagekräftigen Namen (z.B. "Gmail-Posteingang" oder "Tägliche Nachrichten").

  • URL-Muster: Geben Sie die Webadresse (oder einen Teil davon) ein, die diese Website identifiziert.

  • Übereinstimmungstyp: Wählen Sie, wie SiteMarker die aktuelle URL mit Ihrem Muster abgleichen soll.

    Nur Domain – Gleicht nur die Hauptdomain ab (z.B. Muster google.com funktioniert für www.google.com und mail.google.com, aber nicht für google.co.uk).

    Subdomains einschließen – Die URL muss mit Ihrem Muster enden. Beispiel: Muster example.com gleicht sub.example.com und news.example.com ab, aber nicht example.org.

    Teilstring enthalten – Gleicht ab, wenn Ihr Muster irgendwo in der vollständigen URL (einschließlich Pfad und Abfrage) vorkommt. Beispiel: Muster /search gleicht https://www.google.com/search?q=test ab.

    Exakte Übereinstimmung – Die gesamte URL muss genau Ihrem Muster entsprechen (Groß-/Kleinschreibung wird ignoriert). Verwenden Sie dies, wenn Sie Markierungen nur für eine bestimmte Seite wünschen, wie https://example.com/dashboard.

    Regulärer Ausdruck – Für fortgeschrittene Benutzer. Schreiben Sie ein Regex-Muster (z.B. https://.*\.example\.com/.*), um jede Seite unter jeder Subdomain von example.com abzugleichen.

Klicken Sie auf Website speichern. Ihre Website ist nun registriert und Sie können mit dem Platzieren von Markierungen beginnen.


2. Platzieren Sie Ihre erste Markierung

Navigieren Sie zum genauen Absatz, zur Zeile oder Schaltfläche, die Sie sich merken möchten. Tippen Sie dann einmal auf Windows+F12. Der Dialog Markierung hinzufügen wird geöffnet.

  • Muster – SiteMarker füllt dieses Feld automatisch mit dem Text, der sich gerade im Fokus befindet. Sie können es bei Bedarf bearbeiten. Dieser Text wird von SiteMarker durchsucht.

  • Musterabgleich – Wählen Sie, wie das Muster verglichen werden soll:

    Enthält Text – Findet das Muster irgendwo innerhalb des Absatzes (teilweise Übereinstimmung).

    Exakter Absatz – Der Absatz muss exakt mit dem Muster übereinstimmen (vollständige Textübereinstimmung).

    Regex-Abgleich – Verwenden Sie einen regulären Ausdruck für fortgeschrittene Abgleiche.

  • Modus – Legen Sie fest, was diese Markierung tut:

    Springen – Wenn Sie die zugewiesene Sprungtaste drücken, bewegt sich der Cursor zu dieser Markierung. Sie können eine von vier Sprungtasten zuweisen: J, F, D oder Z. Drücken Sie die Taste allein, um vorwärts zur nächsten Markierung mit dieser Taste zu springen. Drücken Sie Umschalt+Taste, um rückwärts zu springen.

    Auto-Klick – Anstatt nur den Fokus zu verschieben, führt SiteMarker automatisch einen Klick auf dem Element aus, wenn Sie die zugewiesene Klicktaste drücken. Die verfügbaren Klicktasten sind Alt+J, Alt+C, Alt+X und Alt+Z.

  • Anzeigename – Geben Sie Ihrer Markierung einen aussagekräftigen Namen (z.B. "Senden-Button" oder "Zusammenfassungsbereich").

  • Versatz – Dies verschiebt die endgültige Cursorposition relativ zur gefundenen Markierung. Geben Sie eine ganze Zahl (positiv oder negativ) ein, um die Landeposition zu verschieben.

    Positive Zahl (z.B. 2) bewegt den Cursor vorwärts um diese Anzahl von Absätzen nach der Markierung.

    Negative Zahl (z.B. -1) bewegt den Cursor rückwärts um diese Anzahl von Absätzen vor der Markierung.

    0 (Standard) landet genau auf der Markierung selbst.

Klicken Sie auf OK – Ihre Markierung wird gespeichert und ist einsatzbereit.



Springen und Klicken wie ein Profi

Sobald Sie Markierungen eingerichtet haben, können Sie mühelos auf Ihrer Website navigieren:

  • Drücken Sie J, F, D oder Z (allein), um vorwärts zur nächsten Markierung zu springen, die dieser Taste zugewiesen ist.
  • Drücken Sie Umschalt+J, Umschalt+F, Umschalt+D oder Umschalt+Z, um rückwärts zur vorherigen Markierung zu springen.
  • Für Auto‑Klick-Markierungen drücken Sie Alt+J, Alt+C, Alt+X oder Alt+Z – der Cursor findet die nächste passende Markierung und klickt automatisch auf das Zielelement.

Jeder Sprung spricht den Zielabsatz vor und bewegt den Bildschirmüberprüfungs-Cursor an diese Position, sodass Sie immer wissen, wo Sie sich befinden.


Alles verwalten

Sie können jederzeit doppelt auf Windows+F12 tippen, um den Site-Manager zu öffnen. Dort können Sie:

  • Den Anzeigenamen, das URL-Muster oder den Übereinstimmungstyp einer Website bearbeiten.
  • Markierungen für jede Website hinzufügen, bearbeiten oder löschen.
  • Alle Markierungen auf einmal löschen.
  • Zwischen der Website-Liste und der Markierungsliste hin- und hernavigieren.

Der Marker-Manager (vom Site-Manager aus zugänglich) bietet Ihnen einen vollständigen Überblick über alle Markierungen für die aktuelle Website mit schnellen Optionen zum Bearbeiten oder Löschen jeder einzelnen.


Markierungen teilen

Alle Ihre Website- und Markierungskonfigurationen werden in einer einfachen JSON-Datei für jede Website gespeichert. Diese Dateien befinden sich in: 

%APPDATA%\nvda\ChaiChaimee\SiteMarker\site\

Sie können diese .json-Dateien auf einen anderen Computer kopieren oder mit Kollegen teilen. Legen Sie sie einfach in denselben Ordner auf dem anderen Gerät, und SiteMarker erkennt sofort die Websites und Markierungen – keine zusätzliche Einrichtung erforderlich. Dies erleichtert das Teilen intelligenter Navigationssetups zwischen Teams oder Geräten.
