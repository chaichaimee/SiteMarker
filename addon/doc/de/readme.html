SiteMarker


Setzen Sie Lesezeichen an beliebige Stellen auf Webseiten und springen Sie mit einem einzigen Tastendruck dorthin zurück.

Einführung

Mit SiteMarker können Sie unsichtbare „Markierungen“ auf bestimmten Textstellen jeder Webseite platzieren und später direkt dorthin springen, oder sie automatisch von NVDA anklicken lassen. Anstatt bei jedem Besuch einer langen Seite mit den Pfeiltasten oder der Tab-Taste durchzunavigieren, drücken Sie eine Tastenkombination und landen genau dort, wo Sie sein müssen — in einem Chat-Fenster, auf einer „Mehr laden“-Schaltfläche, einer bestimmten Überschrift, einer „Werbung überspringen“-Schaltfläche oder allem anderen, das sich wiederholt oder schwer zu finden ist.


Markierungen werden pro Website organisiert. Jede von Ihnen konfigurierte Website erhält ihren eigenen Satz von Markierungen, ihre eigene URL-Abgleichregel und ihr eigenes „Fokus-Modus“-Verhalten. Alles wird automatisch gespeichert, sodass nach der Einrichtung einer Website das Springen und Klicken bei jedem erneuten Besuch dieser Seite sofort funktioniert.

Die Sprungtasten (J, F, D, Z) und Auto-Klick-Tasten (Alt+J, Alt+C, Alt+X, Alt+Z) sind nur aktiv, während Sie sich im Stöber-Modus eines unterstützten Browsers (Chrome, Edge, Firefox, Brave, Opera, Vivaldi oder Thorium) befinden. In jedem anderen Fenster oder wenn eine Website keine Markierung für diese Taste zugewiesen hat, wird die Taste direkt durchgereicht, sodass sie normal tippt oder sich wie gewohnt verhält.

Funktionen

Website-Manager

Jede Website, auf der Sie Markierungen wünschen, muss zunächst als „Website“ hinzugefügt werden. Eine Website wird definiert durch:


Anzeigename — ein benutzerfreundlicher Name, der in der Liste des Website-Managers angezeigt wird.
URL-Muster — die Adresse oder der Domain-Text, der mit der Seite abgeglichen wird, auf der Sie sich gerade befinden.
Übereinstimmungstyp — wie das Muster mit der tatsächlichen URL der Seite verglichen wird:


• Nur Domain — die Domain der Seite muss genau dem Muster entsprechen.
• Unterdomains einschließen — die Domain muss dem Muster entsprechen oder darauf enden (sodass ein Muster wie „example.com“ auch auf „mail.example.com“ passt).
• Teilzeichenfolge enthalten — das Muster muss lediglich irgendwo in der URL vorkommen.
• Exakte Übereinstimmung — die gesamte URL muss genau dem Muster entsprechen.
• Regulärer Ausdruck — das Muster wird als regulärer Ausdruck behandelt und in der URL gesucht.


Fokus-Modus — steuert, wie das normale Fokus-/Formularmodus-Verhalten von NVDA auf dieser Website geändert wird:


• Normal — NVDA verhält sich wie gewohnt.
• Nicht in den Formularmodus wechseln — wenn ein Steuerelement auf dieser Website den echten Windows-Fokus erhält, wird NVDA daran gehindert, für dieses Fokusereignis automatisch in den Formularmodus zu wechseln (der Stöber-Modus bleibt aktiv).
• Fokus deaktivieren — das durch echte Fokusänderungen gesteuerte Umschalten zwischen Stöber- und Fokus-Modus wird auf dieser Website vollständig unterdrückt.


Im Website-Manager können Sie eine Website hinzufügen, bearbeiten oder löschen und direkt in den Markierungsmanager dieser Website wechseln. Das Drücken von Entf auf einer ausgewählten Website (oder F2 zum Bearbeiten) funktioniert direkt in der Liste, und ein Rechtsklick-Kontextmenü bietet dieselben Aktionen.

Markierungsmanager und Markierungseigenschaften

Jede Website verwaltet ihre eigene Liste von Markierungen. Eine Markierung ist eine Regel, die SiteMarker sagt: „Wenn der Text auf dieser Seite dieses Muster erfüllt, ist dies ein Orientierungspunkt.“ Jede Markierung besitzt:


Muster — der zu suchende Text (oder reguläre Ausdruck). Wenn Sie den Markierungseditor direkt von der Seite aus öffnen (über das Einfachtippen von NVDA+Windows+F12), wird dieses Feld automatisch mit Ihrer aktuellen Auswahl, dem aktuellen Absatz unter dem Cursor oder dem Namen/Wert des fokussierten Steuerelements vorausgefüllt, je nachdem, was zuerst verfügbar ist.
Musterübereinstimmung — wie das Muster mit jedem Absatz auf der Seite verglichen wird:


• Text enthalten — stimmt überein, wenn das Muster irgendwo im Absatz vorkommt.
• Exakter Absatz — stimmt nur überein, wenn der gesamte Absatz genau dem Muster entspricht.
• Regex-Übereinstimmung — das Muster wird als regulärer Ausdruck behandelt und innerhalb des Absatzes gesucht.


Modus — ob diese Markierung ein Sprungmarker (verschiebt Ihren Cursor/Einfügemarke dorthin) oder ein Auto-Klick-Marker (aktiviert das Element automatisch) ist.
Taste — welche Tastenkombination diesen Marker auslöst: J, F, D oder Z für Sprungmarker; Alt+J, Alt+C, Alt+X oder Alt+Z für Auto-Klick-Marker.
Suchbereich — Gesamtes Dokument durchsucht die gesamte Seite (und lädt bei Bedarf weiteren Inhalt nach); Nur Ansichtsfenster schränkt die Suche grob auf den aktuell sichtbaren Bereich der Seite ein (ca. 50 Absätze über und unter Ihrem Cursor).
Anzeigename — ein benutzerfreundliches Etikett, das in der Liste des Markierungsmanagers angezeigt wird.
Versatz — wie viele Zeilen (entsprechend einem einmaligen Drücken der Pfeiltaste Nach-oben/Nach-unten) vom übereinstimmenden Absatz entfernt landen soll, von -50 bis +50. Dies ist nützlich, wenn der Text, den Sie zuverlässig abgleichen können, nicht genau die Zeile ist, auf der Sie landen möchten (z. B. wenn Sie den Namen des Autors eines Beitrags abgleichen, aber zwei Zeilen tiefer auf dem Antworten-Button des Beitrags landen möchten).


In der Liste des Markierungsmanagers können Sie eine einzelne Markierung hinzufügen, bearbeiten oder löschen oder alle Markierungen für diese Website auf einmal löschen. Entf und F2 zum Bearbeiten funktionieren ebenfalls direkt auf dem ausgewählten Listenelement, und ein Kontextmenü per Rechtsklick dupliziert diese Aktionen. Wenn Sie die Mehrfachtipp-Tastenkombination auf einem Absatz öffnen, der bereits mit einer der vorhandenen Markierungen der Website übereinstimmt, öffnet SiteMarker diese Markierung direkt zur Bearbeitung, anstatt anzubieten, eine neue hinzuzufügen.

Zu Markierungen springen (J / F / D / Z)

Das Drücken einer Sprungtaste durchsucht Absatz für Absatz, vorwärts oder rückwärts von Ihrer aktuellen Position aus, nach Markierungen, die dieser Taste zugewiesen sind. Sobald eine Übereinstimmung gefunden wird:


1. Wenn die Markierung einen Versatz hat, bewegt SiteMarker sich entsprechend viele Zeilen von dem übereinstimmenden Absatz weg (oder sucht, falls ein Versatzmuster festgelegt ist, nach nahegelegenen Zeilen, die diesem Muster entsprechen, anstatt eine feste Zeilenanzahl zu verwenden), bevor sie landet.
2. Wenn der Versatz Sie auf einem leeren Absatz landen lassen würde, geht SiteMarker so lange weiter vorwärts, bis er auf nicht-leeren Text stößt.
3. Ihr Cursor wird dorthin bewegt und NVDA spricht den Zieltext aus.


Wenn der sichtbare Teil der Seite erschöpft ist, bevor eine Übereinstimmung gefunden wird (z. B. bei einer endlosen „Feed“-ähnlichen Seite), sendet SiteMarker automatisch Bild-Ab, um weiteren Inhalt zu laden, und setzt die Suche bis zu 100 Mal fort. Wenn danach oder nach 5 aufeinanderfolgenden Versuchen ohne neue Inhalte immer noch nichts gefunden wurde, hören Sie „Kein nächster Marker“ oder „Kein vorheriger Marker“.


SiteMarker vermeidet es, genau denselben Punkt zweimal hintereinander anzukündigen (einige Seiten wiederholen identischen Text an mehreren Stellen im zugrundeliegenden Barrierefreiheitsbaum) und überspringt Übereinstimmungen, die in einem editierbaren Feld oder Kombinationsfeld landen, indem es darüber hinwegspringt.

Auto-Klick (Alt+J / Alt+C / Alt+X / Alt+Z)

Das Drücken einer Auto-Klick-Taste durchsucht die Seite von Anfang an nach einer diesem Schlüssel zugewiesenen Markierung, wendet den Versatz auf dieselbe Weise wie Sprungmarkierungen an und klickt dann mithilfe eines dreistufigen Fallbacks auf das übereinstimmende Element, sodass selbst hartnäckige Schaltflächen (wie die „Werbung überspringen“-Schaltfläche einer Videoseite) zuverlässig aktiviert werden:


1. Versuchen Sie den barrierefreien „Aktion ausführen“-Befehl des Elements.
2. Wenn dieser nicht verfügbar ist, versuchen Sie ihn über das UI Automation Invoke-Muster aufzurufen.
3. Wenn beides fehlschlägt, bewegen Sie den Mauszeiger über das Element und simulieren Sie einen physischen Linksklick.


Nach einem erfolgreichen Klick spricht NVDA den angeklickten Text aus und verkündet „Angeklickt“. Insbesondere auf YouTube versucht SiteMarker den Klick automatisch bis zu 2 weitere Male, falls sich die Seiten-URL und der Text unter dem Cursor kurz nach dem Klick nicht geändert haben (ein Zeichen dafür, dass der Klick nicht registriert wurde, was bei einer noch nicht voll interaktiven Überspringen-Schaltfläche passieren kann). Auf anderen Websites wird dieser automatische Erneute-Klick übersprungen, da ein Steuerelement im Umschaltstil beim ersten Klick erfolgreich sein kann, während es unverändert aussieht, und ein erneutes Klicken es einfach wieder ausschalten würde.


Wenn bis zum Ende der Seite kein übereinstimmendes, anklickbares Ziel gefunden wird, wiederholt SiteMarker die gesamte Suche automatisch bis zu 5 Mal mit einer kurzen, ansteigenden Verzögerung zwischen den Versuchen (um Elemente wie die Überspringen-Schaltfläche einer Anzeige abzufangen, die erst ein oder zwei Sekunden nach dem Laden der Seite erscheinen), bevor schließlich „Kein Auto-Klick-Ziel gefunden“ angesagt wird.

Automatische Wiederherstellung bei Fokus-Diebstahl

Auf einigen Seiten kann das automatische „Mehr laden“-Scrollen, das SiteMarker während eines Suchlaufs durchführt, versehentlich den echten Tastaturfokus auf ein unabhängiges editierbares Feld oder Suchfeld lenken, anstatt nur die Seite zu scrollen. Wenn dies während eines aktiven Suchlaufs passiert, stellt SiteMarker den Fokus automatisch wieder auf das Dokument her, damit Ihre Suche nicht unterbrochen wird. Wenn dieselbe Seite den Fokus ungeachtet der Korrekturen immer wieder auf dasselbe Feld zieht, bricht SiteMarker den Scrollvorgang für diesen Suchlauf ab und beendet die Suche einfach mit den bereits geladenen Inhalten.

Hintergrunderkennung von Seitenänderungen

SiteMarker überprüft aktive Markierungen automatisch bei jedem Fokuswechsel, bei Aktualisierungen des Seiteninhalts und in einem periodischen Timer (ca. alle 2 Sekunden), während Sie sich auf einer Browserseite befinden. Dadurch bleiben Ihre Markierungen auf Single-Page-Apps und dynamisch aktualisierten Websites aktuell, ohne dass Sie etwas manuell tun müssen.

Website-spezifische Datenspeicherung

Alle Ihre Websites und deren Markierungen werden automatisch in Ihrem NVDA-Benutzerkonfigurationsordner (unter einem SiteMarker-Ordner) als eine Datei pro Website gespeichert, sodass Ihre Einrichtung zwischen NVDA-Sitzungen erhalten bleibt und für die Funktion keine Internetverbindung erforderlich ist.
